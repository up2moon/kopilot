# 익명 랭킹 페이지

## 페이지 개요

사용자가 동기부여를 얻고 자신의 절약 성과를 타인과 비교해볼 수 있도록 자동 생성된 익명 닉네임과 캐릭터 프로필 기반의 랭킹을 제공하는 화면이다.

하단 탭 바(홈, 랭킹, 챌린지, 투자효과, 마이)를 통해 주요 화면 간 이동이 가능하며, 우측 하단 플로팅 버튼을 통해 언제든지 AI 절약 챗봇으로 바로 이동할 수 있다.

---

## 핵심 기능 및 로직

### 1. 익명 닉네임 자동 생성 조합

타인에게 개인정보가 노출되지 않도록 가입/온보딩 시 무작위 익명 닉네임이 자동 할당된다.

- **생성 규칙**: `[수식어/형용사] + [동물/과일/색상/단어] + [2자리 숫자]`
- **닉네임 조합 예시**:
  - `알뜰한 코알라 27` (내 닉네임 예시)
  - `절약왕 민트 03`
  - `현명한 라임 14`
  - `짠테크 블루 91`
  - `조용한 포도 02`
  - `스마트한 사자 88`
  - `지혜로운 펭귄 05`
  - `소박한 체리 34`
  - `지혜로운 아보카도 19`
  - `부지런한 햄스터 77`

---

### 2. 랭킹 산정 방식 (절약 금액 vs 퀘스트 포인트)

단순 전월 대비 절약 금액만으로 랭킹을 산정할 경우, *"지난달 지출이 기형적으로 커서 이번 달 절약 금액이 억지로 커 보이는 현상(Gaming the System)"*이 발생할 수 있다.

따라서 다음과 같은 산정 구조 및 포인팅 시스템을 고려한다.

- **기본 랭킹 지표 (절약 금액 기준)**:
  - 이번 달 예상 절약 금액 또는 목표 예산 대비 아낀 금액
- **개선/포인트 랭킹 지표 (퀘스트 & 미션 포인트 기준 - 권장)**:
  - daily/weekly 절약 미션(예: 커피 1잔 참기, 무지출 챌린지 성공) 달성 시 포인트 지급
  - `랭킹 점수 = (예산 준수율 포인트) + (절약 퀘스트 달성 포인트)`
  - 지속적인 절약 습관을 유지하는 사용자에게 동등하고 fair한 랭킹 기회 제공

---

### 3. 실시간 vs 주기적 랭킹 업데이트 전략 (배치/캐시)

매번 사용자가 접속할 때마다 전체 데이터베이스를 실시간 집계(SQL `ORDER BY`)하면 성능 저하가 발생한다. 실제 서비스/게임 랭킹 시스템의 표준 구현 방안을 적용한다.

- **업데이트 주기 선택**:
  - **1시간 주기 배치 또는 Redis ZSET(Sorted Set) 5분 캐시**
  - 사용자 화면에는 `1시간마다 업데이트` 또는 `매시 정각 갱신` 안내 표시
- **효과**: 백엔드 DB 부하 방지 및 빠르게 랭킹 리스트 응답

## 화면 구성

### 1. 상단 타이틀 영역

- **타이틀**: `익명 랭킹`
- **서브타이틀**: `자동 닉네임과 프사로 이번 달 절약 랭킹을 확인해요.`

---

### 2. 내 랭킹 카드 (My Ranking Card)

상단에 본인의 랭킹 정보를 강조하여 표시한다.

- **내 프로필 아바타/이모지**: (예: 🦊, 🐨 등)
- **내 익명 닉네임**: (예: `알뜰한 코알라 27`)
- **내 수치**: `이번 달 예상 절약 94,000원` (또는 퀘스트 획득 포인트)
- **내 순위 (우측 강조)**: `8위` (큰 폰트 강조)

---

### 3. 전체 랭킹 리스트 (Top Ranking List)

상위 랭커 순위 목록을 표시한다.

- **1위 🥇**: `절약왕 민트 03` | `182,000원` (금메달 아이콘)
- **2위 🥈**: `현명한 라임 14` | `161,000원` (은메달 아이콘)
- **3위 🥉**: `짠테크 블루 91` | `149,000원` (동메달 아이콘)
- **4위**: `조용한 포도 02` | `132,000원` (숫자 라벨)
- **5위 이하**: 스크롤 형태로 목록 연속 표시

---

### 4. 플로팅 챗봇 버튼 & 하단 네비게이션 바

- **우측 하단 플로팅 버튼**: 말풍선 아이콘 (`💬`) 클릭 시 AI 절약 챗봇 화면으로 즉시 이동
- **하단 5대 네비게이션 탭 (대시보드와 동일)**:
  1. `홈` (대시보드)
  2. `랭킹` (현재 화면, 활성화)
  3. `챌린지`
  4. `투자효과`
  5. `마이`

---

## 백엔드 연동 API

1. **`GET /api/users/me/ranking`**: 현재 사용자의 랭킹 순위, 익명 닉네임, 아바타, 점수/절약액 조회
2. **`GET /api/users/ranking/top?limit=20`**: 상위 랭킹 사용자 목록 조회 (Redis ZSET 또는 1시간 주기 캐시 집계 응답)

## 디자인 및 UX 방향

- **동기부여 강조**: 본인 순위를 상단 카드 형태로 크게 보여주어 긍정적인 경쟁심 유도
- **깔끔한 리스트 UI**: 1~3위 메달 디자인 및 라운디드 카드 스타일 적용
- **직관적인 탭 이동**: 하단 글로벌 네비게이션 및 챗봇 플로팅 버튼을 통해 언제든지 챗봇 및 타 화면 이동 가능
