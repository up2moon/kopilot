# AI 시드머니 로드맵

## 목적

사용자가 목표 금액과 기간을 정하면 AI가 합성 마이데이터 소비를 월·주 단위로 분석하고, 반복 가능한 절약 챌린지로 시드머니를 만들도록 돕는다. 확정 절약액은 사용자 선택 비중에 따라 현금과 국내 상장 S&P 500 ETF 적립식 매수 시뮬레이션으로 나누며, 로드맵에서 현금만 보유한 경우와 현재 평가액을 비교한다.

## 핵심 흐름

```text
목표 금액·기간 설정
→ 최근 90일 소비 분석
→ 월별 필요 금액과 절약 여력 비교
→ 주간 AI 챌린지 추천
→ 절약액 확정
→ 현금·S&P 500 비중 배분
→ CHECK API 기준일 가격으로 가상 매수 원장 저장
→ 현금 보유와 혼합 자산 비교
→ 다음 주 코칭과 비중 조정
```

## 화면

- 홈: 목표 달성률, 이번 달 소비, 오늘의 AI 코칭, CHECK API 기반 최근 소비 기회비용
- 로드맵: 목표 진행률, 현금·혼합 자산 그래프, 투자 비중, 챌린지, 가상 매수 기록
- 챗봇: 목표 생성, 소비 분석, AI 추천 비중, 사용자 비중 수정, 챌린지 조정
- 마이: 계정과 마이데이터 연결 관리

## 시세 및 투자 고지

- 비교 자산은 기본적으로 `360750` 국내 상장 S&P 500 ETF를 사용한다.
- 기준일 및 현재가는 기존 `investment_price`와 CHECK API fallback을 사용한다.
- 실제 증권 주문은 수행하지 않으며 소수점 가상 매수 시뮬레이션으로 표시한다.
- 과거 수익률과 물질적 비교는 미래 수익을 보장하거나 소비 금지를 권유하는 표현으로 사용하지 않는다.
- 현재 가치가 원금보다 낮으면 손실도 그대로 표시한다.

## 데이터

- 기존 `transaction_history`: AI 합성 소비 원천
- 기존 `ai_challenge`: 주간 챌린지와 확정 절약액
- 기존 `investment_asset`, `investment_price`: 종목 및 CHECK API 시세
- 신규 `asset_goal`: 목표·기간·추천 및 사용자 선택 비중
- 신규 `investment_contribution`: 확정 절약액, 가격, 수량 원장
