# 대시보드 페이지 (Dashboard)

## 페이지 개요

로그인 이후 가장 먼저 등장하는 메인 대시보드 페이지이다.

마이데이터를 기반으로 사용자의 이번 달 소비 요약과 AI 절약 코치 추천 카드를 직관적이고 깔끔하게 한눈에 확인할 수 있도록 단일 카드 흐름으로 구성한다.

상세한 소비 추이 차트, 카테고리별 소비, 소비 인사이트, 최근 결제 내역, 자주 이용한 가맹점 등 깊이 있는 지출 데이터 분석은 **`내 소비 상세 (spending-detail.md)`** 페이지에서 다룬다.

---

## 주요 화면 구성 (와이어프레임 기준)

### 1. 상단 브랜딩 및 프로필
* **좌측**: Kopilot 로고 아이콘('K') 및 브랜딩 텍스트
* **우측**: 사용자 프로필 알약 칩 (예: `진` 아바타 + `진원님`)

### 2. 메인 인사말
* **타이틀**: `진원님, 이번 달 소비를 확인해 보세요.` (강조 폰트)
* **서브타이틀**: `마이데이터 기반으로 새는 지출을 정리했어요.` (보조 회색 텍스트)

---

## 핵심 카드 영역

### 1. 이번 달 소비 카드 (White Card)
사용자의 이번 달 핵심 소비 현황을 요약해서 보여준다.

* **제목**: `이번 달 소비`
* **총소비 금액**: `1,245,000원` (가장 크게 강조)
* **지출 변화 상태 칩**: `지난달보다 8.3% 증가` (연한 연황색/살구색 배경의 칩)
* **총결제 건수**: `총 결제 42건`
* **주요 CTA 버튼**: `소비 상세 보기  >` (파란색 `#3182F6` 전폭 버튼 → `/spending` 페이지로 이동)

### 2. AI 절약 코치 카드 (Solid Blue Card)
마이데이터 기반 AI 분석을 통한 절약 팁과 챗봇 이동을 안내한다.

* **상단 라벨**: `AI 절약 코치` (흰색 텍스트)
* **절약 추천 메시지**: `GET /api/users/me/saving-bot/coaching`의 `coaching.message`를 사용해 AI 절약 챗봇의 `오늘의 코칭`과 동일한 내용을 표시한다. 코칭 API를 불러오지 못하면 소비 요약 API의 기존 미리보기 문구를 대체 표시한다.
* **주요 CTA 버튼**: `AI 코치와 대화하기  >` (흰색 전폭 버튼 + 파란색 텍스트 `#3182F6` → `/coach` 챗봇 화면으로 이동)
* **하단 안내 문구**: `질문하면 소비 습관과 절약 미션을 바로 추천해요.` (연한 흰색 보조 문구)
