# 구독 지출 점검 가이드

## 점검 순서

1. 최근 90일 동안 반복 결제된 서비스를 목록으로 확인한다.
2. 최근 한 달 실제 사용 여부를 사용자가 직접 확인한다.
3. 가족이나 다른 계정에서 중복 결제 중인지 확인한다.
4. 연간 결제가 더 저렴하더라도 계속 사용할 서비스인지 먼저 판단한다.
5. 해지 전 저장 데이터와 남은 이용 기간을 확인한다.

## 행동 제안

- 사용하지 않는 구독 한 개만 먼저 점검한다.
- 무료 체험 종료일과 다음 결제일을 달력에 기록한다.
- 비슷한 기능의 서비스가 여러 개라면 가장 자주 사용하는 하나만 남길지 검토한다.

## 주의사항

- 거래내역만으로 실제 사용 여부를 단정하지 않는다.
- 사용자 확인 없이 자동 해지되었다고 표현하지 않는다.
